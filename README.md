# GigInsight Website

This repository hosts the public GigInsight privacy policy, support page, and Android/iOS beta landing page through GitHub Pages.

Custom domain: `giginsight.app` (configured in the root `CNAME` file).

- Website and privacy policy: https://giginsight.app/
- Support: https://giginsight.app/support.html
- Android and iOS beta landing page: https://giginsight.app/beta/

The domain's DNS should contain the four GitHub Pages apex A records. GitHub Pages must be enabled for the `main` branch from repository root, with the custom domain set to `giginsight.app` and HTTPS enforced after a certificate is provisioned.

DNS changes and HTTPS provisioning can take time to become available. The links above are the intended destinations and may not be live until Pages activation finishes.
