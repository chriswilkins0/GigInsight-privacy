Try it yourself

Join the GigInsight public beta

Available to testers on Android and iPhone.

Android · Google Play

Install through GigInsight's official Google Play open test.

  1. Open the Android beta invitation.
  2. Sign in with the Google account used in your Play Store and select Become a tester if prompted.
  3. Use the Play Store link to install or update GigInsight.
Join GigInsight Android Beta

The current open test is version 0.3.1 (Build 14). Play Store availability can lag after an update.

iPhone · Apple TestFlight

Install through Apple's official TestFlight beta testing app.

  1. Open the iPhone TestFlight invitation.
  2. If needed, install the free TestFlight app from the App Store.
  3. Return here and open the invitation again, then tap Accept and Install.
Open GigInsight in TestFlight

If TestFlight asks for a redemption code, come back and tap the invitation link again. No code is needed with the public link while testing is open.
