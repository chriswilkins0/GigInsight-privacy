iPhone beta

TestFlight

Join GigInsight's iPhone beta through Apple's free TestFlight app.

How to install on iPhone

  1. Tap Open GigInsight in TestFlight below.
  2. If you're asked to download TestFlight, install it from the App Store and open it.
  3. Important: If TestFlight asks for a redemption code, you don't need one. Go back to this GigInsight beta webpage and tap Open GigInsight in TestFlight again.
  4. TestFlight should now open the GigInsight invitation. Tap Accept, then Install to start testing.
Open GigInsight in TestFlight

Already have TestFlight installed? Just tap the button above. If the invitation doesn't open immediately, return here and try the button again.

TestFlight is Apple's official beta-testing app. You do not need to create or enter a separate invitation code to join using this public link, provided the beta is accepting testers.

Your feedback matters

During the beta, GigInsight will include tools for bug reports, feature and UI suggestions, market-fit feedback, and GigInsight Pro pricing feedback. We especially want to know what you already use for gig work, what you pay for, and what would make GigInsight worth keeping.
